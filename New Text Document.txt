### 3. Option A: Using SSH Config File (~/.ssh/config) [Recommended]

Add the following block to your `~/.ssh/config` file (on Linux, macOS, or Windows):

```ssh-config
Host my-home-server
    HostName bore.pub
    Port 3124
    User "FIX 11"
    IdentityFile ~/.ssh/agent_id_ed25519
```

> [!IMPORTANT]
> The username **MUST** be quoted as `"FIX 11"`. If you omit quotes (`User FIX`), login will be rejected because the server account is `FIX 11`.

#### Verify Configuration:
```bash
ssh -G my-home-server | Select-String '^(user|hostname|port|identityfile) '
```
*(On Linux/macOS use: `ssh -G my-home-server | grep -E '^(user|hostname|port|identityfile) '`)*

**Expected output:**
```text
user FIX 11
hostname bore.pub
port 3124
identityfile ~/.ssh/agent_id_ed25519
```

#### Connect with a Single Command:
```bash
ssh my-home-server
```

Or run a command directly:
```bash
ssh my-home-server "cd C:\Batter\Batter; git status; docker --version"
```

### 4. Option B: Direct Command Line (Without Config File)

#### Interactive Shell:
```bash
ssh -i agent_id_ed25519 -p 3124 -o StrictHostKeyChecking=no -l "FIX 11" bore.pub
```

#### Run a Single Command:
```bash
ssh -i agent_id_ed25519 -p 3124 -o StrictHostKeyChecking=no -l "FIX 11" bore.pub "cd C:\Batter\Batter; git status; docker --version"
```
