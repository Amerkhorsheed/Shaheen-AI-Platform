# منظومة OSS للذكاء الاصطناعي (OSS AI Platform)
> **المنظومة السيادية للذكاء الاصطناعي — محلية بالكامل ومعزولة عن الإنترنت**  
> واجهة ذكاء اصطناعي متقدمة مستوحاة من **Open WebUI**، مبنية بالكامل بالهوية البصرية السورية (النسر الذهبي، الأخضر الزمردي، الورق الدافئ، الذهب المعتق) ومترابطة محلياً مع **LM Studio**.

---

## 🦅 أبرز الميزات والمواصفات

1. **واجهة مستخدم متقدمة (Open WebUI Style):**
   - تصميم عربي أصيل يدعم اتجاه اليمين لليسار (`dir="rtl"`).
   - شعار النسر السوري الذهبي ذو النجوم الثلاث مدمج في الواجهة والترويسات الرسمية.
   - شريط جانبي قابل للطي يضم تصنيف المحادثات زمنياً (اليوم، الأمس، آخر 7 أيام، السابقة)، تثبيت المحادثات، وتعديل العناوين.
   - دعم كامل للغة Markdown، تنسيق الجداول، وتلوين الشفرات البرمجية مع زر النسخ المباشر.
   - تحكم كامل بمعايير التوليد: اختيار النموذج المحمل، درجة الحرارة (Temperature)، والحد الأقصى للرموز.

2. **عزل محلي تام (100% Offline / Local AI):**
   - ترابط مباشر وحصري مع خادم **LM Studio** المحلي على المنفذ الافتراضي (`http://127.0.0.1:1234/v1`).
   - ممنوع اتصال النموذج بأي خادم سحابي خارجي لضمان السرية التامة للبيانات والمستندات.
   - دعم البث المباشر للردود (SSE Streaming) كلمة بكلمة مع مؤشر الكتابة وإمكانية إيقاف التوليد في أي لحظة.

3. **إدارة المستخدمين وقاعدة البيانات المحلية:**
   - قاعدة بيانات محلية مدمجة **SQLite** (`shaheen.db`) لا تحتاج لأي إعداد أو سيرفر خارجي.
   - نظام تسجيل دخول وحسابات مشفرة بـ `bcrypt` وجلسات JWT محلية.
   - حساب إداري افتراضي جاهز فور التشغيل:
     - **اسم المستخدم:** `admin`
     - **كلمة المرور:** `admin123`
   - لوحة إدارة مستخدمين للمشرف لإضافة حسابات جديدة وتحديد الصلاحيات.

4. **رفع وتحليل الملفات (Upload Files):**
   - دعم رفع الملفات واستخراج نصوصها محلياً:
     - مستندات **PDF**
     - ملفات وورد **Word (DOCX)**
     - ملفات الجداول **Excel (XLSX, XLS)** و **CSV**
     - الملفات النصية والأكواد البرمجية (TXT, MD, PY, JS, JSON, SQL, ...)
   - تضمين محتوى المستند تلقائياً في سياق النموذج للإجابة والتحليل والتلخيص.

5. **آلية التصدير الرسمية المتقدمة:**
   - **تصدير ملفات PDF:** نافذة طباعة مخصصة تحمل ترويسة الجمهورية وشعار النسر الذهبي مع إطلاق أمر الطباعة التلقائي (`window.print()`) ليقوم المستخدم بحفظ المستند فوراً بصيغة PDF عبر المتصفح.
   - **تصدير الجداول (CSV Auto-Save):** رصد الجداول في مخرجات النموذج مع زر تصدير مباشر فوق كل جدول، وإنشاء صفحة تقوم بتنزيل ملف CSV بترميز `UTF-8 with BOM` المتوافق بنسبة 100% مع Microsoft Excel واللغة العربية.

## 🚀 طريقة التشغيل السريع

### 1. المتطلبات:
- **Node.js** (الإصدار 18 فما فوق).
- **LM Studio** (يعمل على نفس الجهاز أو على الشبكة المحلية).

### 2. تجهيز LM Studio:
1. افتح تطبيق **LM Studio**.
2. حمل أي نموذج ترغب باستخدامه (مثل `Qwen 2.5`, `Llama 3`, `Gemma 2`, إلخ).
3. انتقل إلى تبويب **Local Server** (أيقونة السيرفر على اليسار).
4. اضغط على **Start Server** (يعمل افتراضياً على المنفذ `1234`).

### 3. تشغيل المنصة:
من مجلد المشروع:
```bash
# تشغيل الخادم والواجهة الموحدة
npm start
```
أو لتشغيل وضع التطوير:
```bash
# تشغيل خادم الواجهة البرمجية
npm run server

# في نافذة طرفية أخرى، تشغيل واجهة Vite التفاعلية
npm run client
```

افتح المتصفح على:
👉 **`http://localhost:3001`** (أو `http://localhost:5173` في وضع التطوير)

سجل الدخول بالحساب:
- **اسم المستخدم:** `admin`
- **كلمة المرور:** `admin123`
