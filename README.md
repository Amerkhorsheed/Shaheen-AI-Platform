# منظومة OSS للذكاء الاصطناعي (OSS AI Platform)
> **منظومة الذكاء الاصطناعي — محلية بالكامل، مبنية على PostgreSQL 16 + pgvector على Docker، ومعزولة تماماً عن الإنترنت**  
> 🤖 **ملاحظة للوكلاء الذكيين (AI Agents):** يرجى قراءة ملف [`AGENT.md`](./AGENT.md) للاطلاع على دليل التوجيه المعماري الشامل وسجل الترحيل من اللابتوب إلى السيرفر وتفاصيل قاعدة البيانات PostgreSQL.

## 🦅 أبرز الميزات والمواصفات

1. **واجهة مستخدم متقدمة (Open WebUI Style):**
   - تصميم عربي أصيل يدعم اتجاه اليمين لليسار (`dir="rtl"`).
   - شعار النسر السوري الذهبي ذو النجوم الثلاث مدمج في الواجهة والترويسات الرسمية.
   - شريط جانبي قابل للطي يضم تصنيف المحادثات زمنياً، تثبيت المحادثات، وبطاقة الكادر مع شارة القسم والمسمى الوظيفي.
   - دعم كامل للغة Markdown، تنسيق الجداول، وتلوين الشفرات البرمجية مع زر النسخ المباشر.
   - تحكم كامل بمعايير التوليد: اختيار النموذج المحمل، درجة الحرارة (Temperature)، والحد الأقصى للرموز.

2. **الهيكل التنظيمي والتصنيفات المؤسسية الإلزامية (Institutional Categories):**
   - كل مستخدم ينتمي إلزامياً إلى أحد التصنيفات الإدارية المعتمدة:
     - **القيادة والإدارة العليا (`EXEC`)** — سري للغاية (ذهبي).
     - **التحليل والدراسات الاستراتيجية (`STRAT`)** — سري (أخضر زمردي).
     - **الشؤون القانونية والمراسلات الرسمية (`LEGAL`)** — رسمي (أخضر داكن).
     - **المالية والموازنات العامة (`FIN`)** — سري (ذهب معتق).
     - **التحول الرقمي وتكنولوجيا المعلومات (`TECH`)** — رسمي (أزرق ملكي).
     - **التدقيق الداخلي والرقابة والمتابعة (`AUDIT`)** — رسمي (فولاذي).
     - **الموارد البشرية والشؤون الإدارية (`HR`)** — رسمي (بنفسجي).
   - **حقن التوجيه الذكي التلقائي (AI Category Prompt Injection):** يكتشف النظام تصنيف الموظف تلقائياً ويوجه النموذج الذكي للرد وفق تخصص قسمه وصلاحياته.
   - إمكانية إضافة تصنيفات مؤسسية مخصصة جديدة من لوحة الإدارة.

3. **قاعدة بيانات إنتاجية PostgreSQL 16 مع pgvector على Docker:**
   - تعمل قاعدة البيانات داخل حاوية دوكر مخصصة باسم `shaheen-postgres` مع وحدة تخزين دائمة `shaheen_postgres_data`.
   - تم ترحيل كافة البيانات بنسبة 100% (المستخدمين، التصنيفات، القوالب، المحادثات، والرسائل وسجلات التدقيق).
   - تفعيل إضافة `vector` لدعم التضمينات والبحث الدلالي المستقبلي (Semantic Search / RAG).
   - مهايئ قاعدة بيانات Express عالي الكفاءة يدعم المعاملات التلقائية عبر `AsyncLocalStorage`.

4. **إدارة الكوادر والمستخدمين (Production User Management):**
   - واجهة تسجيل دخول إنتاجية نظيفة (بدون بيانات مسبقة أو تلميحات تجريبية) مع زر كشف كلمة المرور وخيار "تذكر اسم المستخدم".
   - لوحة إدارة كوادر متكاملة تضم شريط إحصائيات، بحثاً وتصفية حسب القسم والصلاحية، وتعديل الكوادر، وتجميد الحسابات، وإعادة تعيين كلمات المرور.
   - تشفير كلمات المرور بـ `bcrypt` وجلسات JWT محلية وسجلات تدقيق كاملة (`audit_logs`).

5. **عزل محلي تام (100% Offline / Local AI):**
   - ترابط مباشر وحصري مع خادم **LM Studio** المحلي على المنفذ الافتراضي (`http://127.0.0.1:1234/v1`).
   - ممنوع اتصال النموذج بأي خادم سحابي خارجي لضمان السرية التامة للبيانات والمستندات.
   - دعم البث المباشر للردود (SSE Streaming) كلمة بكلمة مع مؤشر الكتابة وإمكانية إيقاف التوليد في أي لحظة.

6. **رفع وتحليل الملفات وتصدير الوثائق الرسمية:**
   - دعم رفع الملفات واستخراج نصوصها محلياً: مستندات **PDF**، ملفات وورد **Word (DOCX)**، ملفات الجداول **Excel (XLSX)** و **CSV**، والأكواد البرمجية.
   - تصدير رسمي للوثائق المعتمدة بصيغة PDF قابلة للطباعة وترويسة رسمية، وتصدير الجداول إلى Excel و CSV متوافق بالكامل مع اللغة العربية.

## 🚀 طرق التشغيل والنشر (Deployment & Run)

### الخيار 1: التشغيل بنقرة واحدة على ويندوز (Windows One-Click)
قم بتشغيل الملف:
```cmd
start.bat
```
*(يقوم الملف تلقائياً بالتحقق من حاوية `shaheen-postgres` وتشغيلها على المنفذ 5432 ثم تشغيل الخادم على المنفذ 3001)*.

أو عبر الطرفية:
```bash
cmd /c npm start
```

### الخيار 2: التشغيل الشامل بالحاويات عبر Docker Compose
المنظومة مجهزة للعمل بكامل خدماتها (PostgreSQL + التطبيق) مع الربط التلقائي بخادم LM Studio على الجهاز المضيف:
```bash
# بناء وتشغيل الحاويات في الخلفية
docker compose up -d --build

# متابعة السجلات
docker compose logs -f

# إيقاف المنظومة
docker compose down
```

## 🌐 روابط الوصول والعمل عبر الشبكة المحلية (LAN)

- **الرابط المحلي (على نفس الجهاز):** `http://localhost:3001`
- **الوصول من أي جهاز آخر على نفس الشبكة (هواتف، أجهزة لوحية، حواسيب):**
  - عند تشغيل المنظومة عبر `start.bat` أو `npm start`، يكتشف النظام عنوان IP الخاص بجهازك تلقائياً ويعرضه، مثل: `http://192.168.1.161:3001`
  - يكفي فتح متصفح الهاتف أو الجهاز الآخر وكتابة ذلك الرابط للدخول للمنظومة واستخدامها بالكامل.
- **إعداد جدار الحماية (Firewall Setup):**
  - إذا واجهت رسالة تعذر الاتصال من الأجهزة الأخرى، قم بتشغيل الملف:
    ```cmd
    enable-lan.bat
    ```
    (سيطلب إذناً كمسؤول تلقائياً ويفتح المنافذ 3001 و 5173 في جدار حماية ويندوز بنقرة واحدة).
- **حساب المشرف:**
  - اسم المستخدم: `admin` (ينتمي إلى تصنيف **القيادة والإدارة العليا**).
  - كلمة المرور: تُولَّد عشوائياً عند أول إقلاع وتُطبع مرة واحدة في سجل الخادم، ولا تُنشر هنا.
    لاستعادتها لاحقاً: `npm run reset-admin-password`.
  - يمكن للمشرف إنشاء وتعديل الكوادر وتعيين تصنيفاتهم الإدارية وتغيير كلمات المرور من لوحة الإدارة.

## 🧪 التحقق والاختبارات الآلية

**1. فحوصات البنية الأساسية** (قاعدة البيانات، التصنيفات، سلامة بيانات الاعتماد، بناء الواجهة):
```bash
npm test
```

**2. سويت انحدار الأمان** — 21 اختباراً يقابل كل بند من بنود تدقيق 2026-09-06، وتُنفَّذ كطلبات
HTTP حقيقية على خادم قيد التشغيل (لا محاكاة). يجب تشغيل الخادم أولاً:
```bash
npm run test:security
```

يغطي هذا السويت: انعدام أي محتوى مُصطنع عند تعذّر الوصول للنموذج، قابلية التحقق من الأرقام
الإشارية وبصمات SHA-256، إغلاق التسجيل الذاتي، إلزام التوثيق على مسارات التصدير، تعقيم
المدخلات (XSS)، منع الوصول لجلسات مستخدمين آخرين (IDOR)، الإبطال الفوري للجلسات عند
التجميد أو الحذف، رفض عناوين النماذج الخارجية (SSRF)، وترويسات الأمان.

> لا يتضمن السويت أي تأكيد على كلمة مرور محددة: اختبارٌ يثبّت كلمة مرور ضعيفة يجعل إصلاحها
